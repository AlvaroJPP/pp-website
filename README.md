# PP Auto Peças — Website

Landing page responsiva para a PP Auto Peças, em Vila dos Cabanos, Barcarena — PA.

## Conteúdo
- Página inicial e apresentação da loja
- Categorias ilustrativas de peças e acessórios automotivos
- Seção sobre a empresa
- Endereço completo e mapa incorporado
- Link para abrir a rota no Google Maps
- Layout responsivo para desktop e celular

## Publicação no GitHub Pages
O workflow em `.github/workflows/pages.yml` publica o site automaticamente quando há push na branch `main`.

1. No GitHub, abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **GitHub Actions** como fonte.
3. Aguarde o workflow terminar em **Actions**.

Depois da primeira publicação, o site ficará disponível em:
https://alvarojpp.github.io/pp-website/

## Personalização
O site é estático e não exige instalação de dependências. O conteúdo, estilos e scripts estão no arquivo `index.html`.

As categorias são exemplos visuais; confirme catálogo, disponibilidade, horário de funcionamento e contatos da loja antes de divulgar essas informações.
